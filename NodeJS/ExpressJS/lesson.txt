// Route Parameters
/api/courses/:id/year
Here  id and year are route parameters...
- req.params is used

//Query Parameters
Anything after ? in order to get better detailed view
/api/courses/year/month?sortBy=name
- req.query is used

// POSTMAN can be used for calling endpoints for POST requests

// Middleware
A middleware is a function which takes the request and send back the response or pass the request to another middleware
-Every Route Handler Function is a middleware where client request are handled
- .use(express.json()) is also a middleware
It finds json in the body of the request and then it passes the json object in the req.body finally..

// Request Processing Pipeline
Request --> Middleware --> Middleware --> Response
Example
Request --> json() --> route()  --> response

Built in middleware
json 
urlencoded --> express.urlencoded({extended:true});
-This extended true is used in order to parse complex objects
static
app.use(express.static('public)); //In this all files of frontend can be used here

// Third Party Middleware 
helmet //Securing various http headers...
morgan // Logs all the request...
